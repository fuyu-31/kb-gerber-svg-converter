# kb-gerber-svg-converter

 # 対応仕様

 RS-274X 基本コマンド
 単位指定: MOMM / MOIN
 座標形式指定: FS（先頭/末尾ゼロ省略）
 絶対座標 / インクリメンタル座標
 円形アパーチャ C
 矩形アパーチャ R
 オーバルアパーチャ O
 正多角形アパーチャ P
 D01: 描画
 D02: 移動
 D03: フラッシュ
 G01: 直線補間
 G36 / G37: 領域描画
 LPD / LPC: 描画極性
 基本的な穴あき円形アパーチャ
 Excellonの基本的なドリル座標
 # 未対応または制限あり
 Gerberマクロ AM
 複雑なマクロアパーチャ
 Excellonのスロット加工
 一部の拡張仕様
